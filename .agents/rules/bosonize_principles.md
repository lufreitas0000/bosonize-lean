# Bosonize-Lean scientific principles and version scope

Scientific value lies in parameterized structural proofs, explicit hypotheses
and regulator residuals, universally quantified over the admissible regulator
family. Use concrete finite calculations for non-vacuity, examples and falsification;
use numerical tools for numerical exploration. Keep every projection remainder
until its vanishing is proved on the actual source/target carriers.

Distinguish finite CAR, uncompressed polynomial CCR, coefficientwise formal series
and analytic limits. Never infer state existence, positivity, physical comparison,
surjectivity or unitary implementation from a scalar parameter substitution.
Review the mathematics before specifying or coding a new interface.

Version 1 is standalone. CH20's finite theorem package is complete; CH20b is a
working name for the unresolved Chapter 20 bridge, not a new numbered chapter.
The current user scope is status/Git reconciliation and independent theoretical
prompts. Do not start CH20b/CH21 implementation until a clear reviewed strategy
and subsequent user direction. Version 2 is a future complete refactor built on
finiteQMB; no dependency or Core architecture change is authorized now.
