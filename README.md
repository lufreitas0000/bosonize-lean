# Bosonize-Lean: Exact Lattice AQFT Bosonization in Lean 4

**Overview:**
Bosonize-Lean is a rigorous formalization of 1+1-dimensional algebraic quantum field theory (AQFT) bosonization, written in Lean 4. The foundational philosophy of this project is the elimination of analytical limits, unbounded operators, and topological approximations. Every claim in this repository is formalized as an exact identity on finite-dimensional vector spaces or multivariate polynomial rings.

**Core Methodology (The Lean-First Approach):**
This project treats the Lean 4 kernel as the ultimate source of truth. We use a highly focused LLM orchestration loop powered by the Model Context Protocol (MCP). Agents interact directly with the Lean compiler to read tactic states, search Mathlib, and parse diagnostic feedback in real-time.

**Repository Structure:**
*   **`Bosonize/Core/`**: The immutable, verified Lean 4 library. Files here must compile with zero warnings, zero `sorry` placeholders, and rely only on standard axioms.
*   **`BosonizeStubs/`**: The staging area for draft definitions and theorem signatures currently under active proof development.
*   **`notes/md/`**: The mathematical source of truth.
*   **`docs/companion/`**: The mirrored lab notebooks generated by the AI agent during the drafting phase, capturing design rationale and tactical strategies.

**Development Workflow:**
We build knowledge cumulatively. Each chapter is drafted as a set of theorem signatures (stubs) alongside a mirrored lab notebook. The human architect reviews the notebook and locks the signatures. The agent then executes an interactive proof search, utilizing the mathematical proof sketches from the notes to guide its tactics. Once verified, the file is frozen into the core library.
